# Security policy

SwiftRAR parses untrusted archives, so crashes, hangs, excessive memory use
and anything that escapes the `Limits` you passed are security issues.

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately to the maintainer,
@polderpijplijn on GitHub. Once the repository is public, use GitHub's
private vulnerability reporting (Security > Report a vulnerability).

Include the SwiftRAR version, the platform, and if possible the archive
that triggers the problem (or a way to make one). You will get a reply
within a week. A fix comes with a regression test and a changelog entry.
